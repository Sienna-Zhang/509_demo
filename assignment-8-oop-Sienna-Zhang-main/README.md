# Assignment 8: OOP & Algorithms

## 1. Problem Description
This repository contains solutions for Assignment 8, focusing on Object-Oriented Programming (OOP) and algorithm implementation in Python. It consists of three distinct projects:
1. **Tic-Tac-Toe**: A command-line game implementing MVC architecture.
2. **Linear Regression Toolkit**: A custom implementation of Linear Regression using the Normal Equation with Ridge Regularization.
3. **Grid World Navigation**: A simulation of an agent finding the shortest path in a grid using Breadth-First Search (BFS).

## 2. How to Run the Solution

### Prerequisites
- Python 3.x
- Virtual Environment (recommended)

### Setup
1. Clone the repository.
2. Navigate to the project root.
3. Install dependencies (if any) for specific sub-projects as detailed in their respective READMEs.

### Running Sub-projects
Each sub-project is self-contained in its own directory. Please refer to the `README.md` within each folder for specific running instructions:
- **Tic-Tac-Toe**: `cd tic_tac_toe`
- **Linear Regression**: `cd LR`
- **Grid World**: `cd GW`

- **Algorithms**: 
    - **Minimax/Heuristics** (implied in Tic-Tac-Toe logic).
